Hermes needs an OpenRouter key

Hermes is installed on this runner, @RUNNER@, but won't start until the runner is granted the openrouter-api-key secret.

1. Get a key from OpenRouter

  1. Sign in at openrouter.ai.
  2. Add some credit on the Credits page.
  3. Create a key on the Keys page, and copy it. It starts sk-or-.

2. Save it as a secret

On the host of this runner's adapter, signed in with bh auth login. This asks for the key, so it stays out of your shell's history:

printf 'Key: '; read -rs KEY; echo; printf %s "$KEY" | bh host adapter secret set openrouter-api-key; unset KEY

3. Grant it to this runner

bh host adapter secret grant openrouter-api-key --runner @RUNNER@

You can do steps 2 and 3 on the control plane's Secrets page instead.

Hermes starts within about 10 seconds of the grant, and this page changes to it by itself.
